# Python Learning Repository

This repository is a collection of Python practice work focused on data analysis and computer vision. It brings together Jupyter notebooks, CSV/Excel datasets, Python scripts, and image assets used for hands-on learning and experimentation.

## Overview

- Pandas folder: contains multiple notebooks for data cleaning, merging, missing value handling, exploratory data analysis, sentiment analysis, and dataset-based exercises such as Bollywood, IPL, Heart, Employee, Cereals, and several end-semester practice notebooks.
- Datasets folder: includes sample datasets in CSV and Excel formats used across the notebooks, such as cereals, heart monitoring, Hypermart, insurance, deliveries, IPL matches, and sentiment data.
- computer-vision folder: contains Python scripts and a notebook for learning image processing and computer vision concepts.
- Photos folder: stores sample image files used in visual/computer vision exercises.

## Purpose

The repository is intended for learning and practicing key Python skills, including:

- data wrangling and preprocessing with pandas
- working with real-world datasets
- exploratory data analysis and visualization
- sentiment and statistical analysis
- basic computer vision scripts and image-based tasks

## Repository Structure

- `Pandas/` — notebooks and scripts for pandas/data analysis practice
- `Datasets/` — input data files for analysis exercises
- `computer-vision/` — computer vision learning scripts and notebook
- `Photos/` — sample images used in visual tasks

This repo serves as a practical sandbox for building Python, data analysis, and CV fundamentals through small projects and exercises.
